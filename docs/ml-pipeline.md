# ML Pipeline

沿用课件流程：CSV → Colab / 本机 → int8 TFLite → `model.h` → Arduino。

## 数据搜集

- 4 人以上，每类 50–100 次；左右手、快慢都要有。
- 另录每人 15 分钟 `background`：拨头发、挥手、推眼镜、走路、拿水杯。**没有这类，demo 时观众一动就误触。**
- 可选：FSR 压力垫打一次校准，给力道分级当真值。
- 存放：`data/<受试者代号>/<类别>/<时间戳>.csv`，字段 `t_ms,ax,ay,az,gx,gy,gz`。

## 前处理

- 窗口：以触发点为中心，1 s × 100 Hz × 6 轴 = 600 值（窗口长度是实验 2 的扫描变量）。
- 归一化：用训练集的 per-channel mean/std，写进 `model.h` 一起导出。
- 增强：time-shift ±100 ms、高斯杂讯、幅度缩放 0.8–1.2。

## 切分

**依人切分**：同一人的数据不能同时出现在 train 和 test。另跑留一人交叉验证（实验 4）。

## 模型

| 候选 | 参数量级 | 备注 |
|---|---|---|
| Dense 600-32-16-N | ~20k | 基线，课件同款 |
| 1D-CNN（2 层 conv + GAP） | ~10k | 预期较准、较小 |

目标：int8 后模型 < 50 KB、tensor arena < 30 KB，才留得下 BLE stack 的 RAM。

## 设备端触发

```
每笔采样 → 更新环形缓冲
|a| > A_TH（初值 2.5 g）且不在冷却期 → 再收 0.5 s → 取窗口推论
conf < C_TH → 当作 background 不送
送出后冷却 400 ms
```
