# 量化实验

这一节决定报告是研究还是玩具。每个实验都要有表格或图。

| # | 实验 | 自变量 | 量测 | 产出 |
|---|---|---|---|---|
| 1 | 量化影响 | FP32 vs int8 | 模型大小、准确率、单次推论延迟（Nano 上 `micros()`） | 表 |
| 2 | 窗口 / 采样率扫描 | 窗口 0.5/0.75/1.0/1.5 s；采样 50/100 Hz | 准确率、延迟、RAM 占用（BLE stack vs tensor arena） | 折线图 + RAM 堆叠图 |
| 3 | 边缘 vs 集中推论 | Nano 端推论 vs 串 raw 到 ESP32 推论 | BLE 带宽、端到端延迟、Nano 功耗 | 表 |
| 4 | 跨用户泛化 | 留一人交叉验证 | 每人准确率、混淆矩阵 | 箱形图 + 混淆矩阵 |
| 5 | 对时精度 | 有 / 无 sync beacon | 两节点时间戳残差分布 | 直方图 |
| 6 | 误触率 | 有 / 无 background 类、有 / 无阈值 | 每分钟误触次数（15 分钟自由活动） | 表 |

脚本放在 `tools/`，原始量测结果放在 `results/`（自行创建）。
